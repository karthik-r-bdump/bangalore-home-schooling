# ICSE Content Creator Skill

This skill guides the creation of high-quality educational content, chapter summaries, question banks, and worksheets aligned with the Council for the Indian School Certificate Examinations (CISCE) curriculum.

---

## 🎯 When to Use

Use this skill whenever:
- Creating or expanding notes for any subject from **Pre-KG to Class 10**.
- Designing ICSE question banks (MCQs, 2-mark definitions, 3-mark conceptual questions, 5-mark structured questions).
- Generating practice worksheets, flashcards, or mock test papers.
- Designing homeschooling lesson plans and hands-on home experiments for Bangalore homeschoolers.

## 💡 Best Practices for Homeschooling Context
1. **Hands-on Integration**: When discussing science topics, suggest simple kitchen/home experiments or visits to Bangalore locations (VITM museum, Lalbagh, Jawaharlal Nehru Planetarium).
2. **Encouraging Tone**: Frame questions and notes to build genuine curiosity and confidence.
3. **Step Marking**: Always make mark distributions transparent so students understand how ICSE board examiners assess answers.
