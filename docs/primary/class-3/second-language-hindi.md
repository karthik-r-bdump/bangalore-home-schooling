# Class 3 Second Language
## Topics Covered
- Vyakaran (Grammar): Sangya (Noun), Sarvanam (Pronoun), Kriya (Verb), Visheshan (Adjective).
- Reading: Short stories with moral lessons, poetry recitation.
- Writing: Nibandh (Essay), Chitra Varnan (Picture Description), Vakya Rachna.
