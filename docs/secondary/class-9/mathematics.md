# Class 9 Mathematics (80 Marks)

## Syllabus & Key Topics
- Pure Arithmetic, Commercial Math (Compound Interest), Algebra (Expansions, Factorisation, Simultaneous Linear Equations, Indices, Logarithms), Geometry (Triangles, Rectilinear figures), Trigonometry, Coordinate Geometry, Mensuration.

## 🧮 High-Yield Formulas
$$A = P \left(1 + \frac{r}{100}\right)^n$$
$$(a+b+c)^2 = a^2+b^2+c^2+2(ab+bc+ca)$$

## 📝 Sample ICSE Board Questions
1. Factorise completely: $x^3 - 3x^2 - 10x + 24$.
2. Solve the simultaneous equations: $3x + 2y = 11$, $2x + 3y = 4$.
