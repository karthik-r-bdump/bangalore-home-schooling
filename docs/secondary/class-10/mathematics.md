# Class 10 Mathematics (80 Marks)

## Syllabus & Key Topics
- Commercial Math (GST, Banking - Recurring Deposit), Algebra (Linear Inequations, Quadratic Equations, Remainder & Factor Theorem, Matrices, Arithmetic Progression), Geometry (Similarity, Circles, Tangents), Mensuration (Cylinder, Cone, Sphere), Trigonometry (Identities, Heights & Distances), Statistics & Probability.

## 🧮 High-Yield Formulas
$$\text{Recurring Deposit: } I = P \times \frac{n(n+1)}{2 \times 12} \times \frac{r}{100}$$
$$\text{Quadratic Formula: } x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

## 📝 Sample ICSE Board Questions
1. A man has a Recurring Deposit Account of ₹1,000 per month at $10\%$ p.a. simple interest. If he receives ₹33,250 on maturity, find the total time (in months) for which the account was held.
2. Find the value of $k$ for which the quadratic equation $(k-4)x^2 + 2(k-4)x + 4 = 0$ has equal roots.
